## ✨ Overview
**GraphLit** is your **smart data visualization companion**.  
Upload your dataset (CSV/Excel) and instantly generate **beautiful, interactive charts & dashboards** — no coding required.

Built with **Streamlit + Plotly**, GraphLit helps you:
- Quickly explore datasets
- Create interactive charts
- Detect duplicates, outliers, and insights
- Build dashboards in seconds
- Export or share visualizations

---

## 🚀 Features
✅ **Upload data** (CSV, Excel, Paste CSV)  
✅ **Quick Clean** – remove duplicates, drop nulls, select columns  
✅ **Global Filters** – apply conditions across all charts  
✅ **Smart Visualizations**  
   - Line, Bar, Scatter, Pie, Histogram, Box, Heatmap  
   - Aggregations (mean, median, sum, max, min, mode, count)  
✅ **Custom Styling**  
   - Dark modern UI  
   - Multiple color palettes  
   - Legends & axis formatting  
✅ **Dashboard Mode**  
   - Add charts with 1 click  
   - Reorder, remove, and curate your visual story  
✅ **Insights Panel** – auto summary of dataset
